# Branch Protection Rules для main

Для ветки `main` задана следующая целевая конфигурация GitHub/GitLab:

- изменения только через Pull Request;
- не менее двух одобрений, включая владельца кода для миграций;
- сброс устаревших одобрений после нового push;
- обязательное разрешение всех обсуждений;
- обязательные проверки `build-and-test` и `migration-lint`;
- обязательное обновление ветки относительно `main` перед слиянием;
- запрет force push и удаления ветки;
- запрет обхода правил администраторами;
- линейная история и squash merge.

Файл `.github/CODEOWNERS` назначает отдельного проверяющего для SQL-миграций и
ADR. Имена-заглушки заменяются на фактические учетные записи после создания
удаленного репозитория.
